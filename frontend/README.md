# PeopleOps Frontend

Angular SPA for the Employee Management Service.

## Run locally

```powershell
npm install --registry=https://registry.npmjs.org/
npm start
```

Opens on **http://localhost:4201** and calls the API at **http://localhost:8081/api**.

## Build

```powershell
npm run build
```

Output: `dist/frontend/browser` (or `dist/frontend` depending on Angular builder layout).
